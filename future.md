# 🔮 Open Questions 🔮


Questions I've named in public and haven't answered yet. Some need time. Some need hardware.


- **The automated route.** What happens when a local model's output flows straight back into an agentic workflow, with no human copy step in between? Version 1 is me, by hand. Version 2 is the pipeline, its gate tests, and the mistakes I make building it.
- **The night every agent stopped.** With poisoned files planted on both sides of a cage run, the blue agents started refusing, then the red agents, then every agent on both teams. One observation. No mechanism. Doing it properly needs local models that can carry the work, and the hardware to run them.
- **Canary files.** Does an agent pull a planted file's words into its own context, or pass them along as data? That distinction is the whole mechanism, and I haven't measured it.
- **A memory that knows when to forget.** A per-session index of pointers back into the files that matter, thrown away every session because line numbers move. Named on stage twice. Shipped zero times.
- **A three-swarm fleet.** Swarnam for depth against a single target, a breadth swarm for events where every red teamer hits every team, and a coordination plane to act as the command center.
- **Bigger models.** The current route runs 7 to 9 billion parameter models on an 8 GB card. Better hardware would mean better answers.
